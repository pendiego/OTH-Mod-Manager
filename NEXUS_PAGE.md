## Summary (max ~350 chars)
A mod manager for over the hill. Drag in a .zip/.7z/.rar, or install from Nexus in one click. It detects your game, installs MelonLoader/BepInEx for you, toggles mods and liveries, and tells you when a mod has an update. Português e English.

## Description (BBCode)
```
[size=5][b]OTH Mod Manager[/b][/size]
A simple mod manager for [b]over the hill[/b]. No manual file copying.

[size=4][b]What it does[/b][/size]
[list]
[*][b]Drag and drop[/b] a .zip, .7z or .rar and it installs in the right place (mods, BepInEx plugins and livery packs).
[*][b]Loaders handled for you[/b]: if a mod needs MelonLoader or BepInEx, the app offers to install and activate it. Only one runs at a time.
[*][b]Explore[/b] every Nexus mod for the game inside the app, with search, a loader filter and Installed / Update available badges.
[*][b]One-click install[/b] with a Nexus account: Premium installs straight from the app, free accounts use the "Mod Manager Download" button on the mod page.
[*][b]Dependency check[/b]: it warns you when a required mod is missing.
[*][b]Turn mods and liveries on/off[/b] or remove them, without losing files.
[*]Detects the Steam install automatically. Português (BR) and English.
[/list]

[size=4][b]How to use[/b][/size]
[list=1]
[*]Install with the setup file and open OTH Mod Manager. A short welcome guides you.
[*](Optional) Paste your personal Nexus API key in Settings to install from Nexus.
[*]Open [b]Explore[/b] and click Install, or drag a file you already downloaded into the window.
[*]Click [b]Play[/b].
[/list]

[size=4][b]Good to know[/b][/size]
[list]
[*]The first launch with a loader is slow (minutes). MelonLoader may ask to install .NET 6.
[*]Your Nexus API key is stored only on your computer, in the app settings. It is only sent to Nexus.
[*]The app only touches the game folder, [i]My Games/over the hill/LocalLiveries[/i] and its own data folder. Mods installed through the app are tracked, so removing one deletes exactly its files.
[*]The installer is not code-signed, so Windows SmartScreen may show a warning. See the SHA-256 in the file description and the source link below.
[/list]

[size=4][b]Requirements[/b][/size]
Windows 10/11 with WebView2 (already included in Windows 11), and over the hill on Steam.

[size=4][b]Source and support[/b][/size]
MIT licensed. Source: [url=REPO_URL]REPO_URL[/url]. Bugs and ideas: use the Posts/Bugs tabs or open an issue.
```
